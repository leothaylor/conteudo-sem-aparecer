# QA — execução local

Verificações automatizadas disponíveis neste ambiente:
- HTML, CSS e JavaScript de sintaxe validada;
- sem URLs de checkout falsas;
- todas as imagens existem e possuem descrições alternativas;
- não há scripts externos de rastreamento;
- os links internos apontam para IDs existentes;
- o produto e o preço correspondem aos valores informados;
- imagens são otimizadas e o projeto funciona sem frameworks.

**Limite conhecido:** não foi possível concluir captura de tela via Chromium neste ambiente: acesso local ao navegador automatizado bloqueado pelo administrador. É recomendada inspeção visual em desktop e mobile na máquina do usuário antes de ativar o checkout e publicar o link.
